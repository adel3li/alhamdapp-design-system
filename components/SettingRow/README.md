# SettingRow

A settings line: label at the start, value and/or toggle at the end — the time-picker row.

**Consumer provides:** label, optional value (Arabic-Indic numerals, e.g. «٧:٠٠ صباحًا» in `gold-bright`), optional Toggle, onPress for the row.

- `glass-inset`, 1px `hairline`, `radius-button` (16), padding 14×16, 15px label, min-height `tap-min`.
