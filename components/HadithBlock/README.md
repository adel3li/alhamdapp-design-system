# HadithBlock

A hadith or du'a in « », Amiri 19–20px / 1.9, `text`; source line «رواه مسلم · صحيح» at 12px `text-muted`.

**Consumer provides:** text with diacritics as given, narrator/grade line.

- Shown as given, no truncation. Usually inside a GlassCard titled «حديث اليوم» with a `gold-bright` dot and a share icon.
- The spec keeps hadith in `text`; the current home screen renders it in gold — align the screen to the spec (gold is for ayat).
