# ShareCard

Exported image of a blessing: 1080×1350 (post) and 1080×1920 (story). Always the dark «ليل» ground, whatever theme the app is in.

**Consumer provides:** category eyebrow, blessing title, ayah + reference.

- Layout: `ground`; a GlassCard (radius 48 at 1080 scale, 2px `hairline`) holding the `gold-deep` eyebrow (600), the Amiri title over a hairline rule, the ayah in Amiri Quran `ayah` colour with ornate ﴿ ﴾, and the reference in `text-muted`.
- Footer: the Wordmark (`text` word, gold thread) centred, tagline «نعمةٌ كلَّ يوم» in `text-muted`. The v1 spec placed the mark bottom-left; the shipped cards centre it — centre it.
- The story format only adds top space; the card stretches.
