# PromptCard

A numbered reflection question with its answer field (the «نعمة جديدة» compose form has three).

**Consumer provides:** number (Arabic-Indic), question, answer value/onChange.

- `glass-inset`, `hairline`, `radius-button`, padding 16. Number: 26px `violet` disc, `on-violet` 13px. Question 15px/600. Textarea per SearchField.
- Every question is optional; the three answers are stored as separate fields.
