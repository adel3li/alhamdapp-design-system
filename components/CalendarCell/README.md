# CalendarCell

A Hijri day in المداومة. Three states only:

- Plain: `text-muted` numeral.
- Done (`is-done`): `text-body` numeral + 5px `gold-deep` dot.
- Today (`is-today`): 36px ring, 1.5px `violet`, `text` numeral.

**Consumer provides:** day number (Arabic-Indic), state.

- No streak counters, no badges, no styling for missed days — this is a no-pressure app. Summary line: «أتممتَ ٩ أيامٍ من ذي الحجة».
