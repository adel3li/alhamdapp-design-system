# SearchField

Inset text input and textarea.

**Consumer provides:** placeholder (Arabic, ending «...»), value, onChange.

- Input: `ah-field` — `glass-inset` fill, 1px `hairline`, `radius-field` (12), padding 14×16, 15px `text`; placeholder `text-muted`.
- Textarea: add `ah-textarea` — sits on `ground` inside a prompt card, 14px, min-height 64, no resize.
- Focus: `accent` border plus the 2px `accent-text` focus ring.
