# JournalEntry

One «سجل الحمد» entry: GlassCard with the blessing chip, the user's text (`body`, `text`), and the time (`label`, `text-muted`, clock icon) at the end. Grouped under a Hijri day label («الأحد ٢٥ ذو الحجة», 14px `text-muted`).

**Consumer provides:** blessing name, entry text, time (Arabic-Indic, «٩:١٤ م»), onPress.

- Keep the time on one line — never let «م» wrap under the numerals.
- Entry text never leaves the device.
