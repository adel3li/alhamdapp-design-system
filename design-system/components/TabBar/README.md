# TabBar

Bottom navigation — exactly four items, labels on every screen: الرئيسية · سجل الحمد · المداومة · الإعدادات.

**Consumer provides:** the active route (`aria-current="page"`), handlers.

- `glass-raised`, 1px `hairline`, `radius-sheet` (20), `shadow-raised`. Items: Lucide 24 (stroke 1.5) over an 11px label, `text-muted`.
- Active: `accent-text` icon and label with a 22×3 `accent-text` bar above; inactive `text-muted`. No badges, no counts.
- The tasbih (المسبحة) is reached from a home card, not the bar.
