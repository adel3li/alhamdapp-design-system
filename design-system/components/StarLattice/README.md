# StarLattice

Background pattern of eight-point stars (two overlapped squares, one 140px tile), stroke only, in `lattice-stroke` (text at 5%).

**Consumer provides:** the screen it covers — **onboarding and reflection only** (`ground-deep` / `ground-deepest`). Never on home, journal, calendar or settings.

- Class `ah-lattice` (sets `ground-deep` + the tile; the light theme swaps the stroke to ink). The tile is also an asset: `assets/Patterns/star-lattice.svg` (stroke `#EDEDF5`).
- `ah-cone`: in ليل an optional radial wash of `cone` (≤6%) behind «نعمة اليوم» — drop it if it fights the glass. In نهار the same class paints two soft blobs of `cone` (ground-deepest at 60%) instead.
